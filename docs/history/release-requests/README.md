# Historical patch release requests

These **48 historical release-request files** were moved from `.github/release-requests/` to this folder after the stable `v1.0.0` release.

- All file contents and original names are **byte-identical** (Git blob SHA unchanged).
- The originals also remain at their historical paths in the immutable [v1.0.0 source tree](https://github.com/heller-adrian/Bibliothekar/tree/v1.0.0/.github/release-requests).
- The active patch workflow still uses **newly committed** `.github/release-requests/*.txt` files on an authorized `patch/**` branch.
- Files stored here are historical evidence and **must never be interpreted as a new publication approval**.
- Nothing here changes the installed application, the 1.0.0 image, historical tags or GitHub Actions run records.

For a later release, follow the current [release procedure](../../RELEASING.md). Do not reuse old request files as authorization for publication. The entire Git history and old branches still need a privacy check before the repository becomes public.
