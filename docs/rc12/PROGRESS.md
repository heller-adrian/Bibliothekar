# RC12 Arbeitsstand

2026-10-27: Basis v1.0.0-rc.11 (d275b4a9), eigener Zweig release/v1.0.0-rc.12. Wochenbudget Start 55 % verbraucht, Aufgabenobergrenze 65 %. Legacy-Profil behält RC11-Vertrag; keine automatische Umdeutung. Lokale 15 RC12-Prozess-/HTTP-Tests bestanden (synthetischer RO-Archivnachweis; echte RO-Mounts folgen im Linux-Container). Historische Regressionen laufen.
